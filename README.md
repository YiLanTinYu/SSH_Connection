# AOMT

**交换机自动化运维工具（Automated Operations and Maintenance Tool）**

AOMT 是一款面向网络运维人员的 Windows 桌面工具，使用 Python 和 PyQt5 开发，用于集中管理 H3C Comware 与 Huawei VRP 交换机，并辅助完成日常 SSH 运维工作。

## 项目简介

AOMT 将设备管理、批量任务和常用网络工具整合在统一的图形界面中。它支持从 Excel 导入设备、按范围选择目标、批量执行命令、巡检与备份配置，也提供 SSH/串口交互终端、网络检测、文件传输、抓包、配置对比和常用配置模板等辅助能力。

项目注重执行前确认、结果留痕和敏感信息保护。用户业务命令按原文发送，不进行未经验证的跨品牌自动转换。

## 主要特点

- 支持 H3C Comware 和 Huawei VRP
- 支持 IPv4、IPv6、设备分组和批量任务
- 支持统一脚本及按设备名称匹配独立脚本
- 提供巡检、配置备份、诊断和结果导出
- 集成交互终端及常用本机运维工具
- 支持加密 Excel 中的设备认证信息

## 运行环境

- Windows 10 / 11
- Python 3.11
- PyQt5
- Nuitka（用于构建 Windows 发布包）
